# Visual Review Portfolio — Sunil Singh

A responsive static portfolio featuring a newly prepared visual brand review sample.

**Live portfolio:** https://suniel11.github.io/visual-review-portfolio/

## Contents

- An invented Northline brand brief with five explicit requirements
- Two contrasting typography-led creatives
- A criterion-by-criterion comparison and concise selection rationale
- Review methodology and ambiguity handling
- A link to development projects

This is a sample case study, not a client engagement or evidence of past professional brand-design work.

## Run locally

No dependencies or build step are required. Open `index.html` in a browser, or run:

```sh
python -m http.server 8000
```

Then visit http://localhost:8000.

## Implementation

Semantic HTML, embedded responsive CSS, accessible navigation and comparison table. No third-party scripts or tracking.
