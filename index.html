01 / Visual brand review

One brief. Two directions.

Sample case study · September 2026

A typography-led digital creative comparison for Northline, an invented home-goods brand. Both layouts communicate the same offer; the review checks fidelity to the brief rather than personal taste.

The brand brief

Practical, calm, and direct. Help shoppers understand the collection without exaggerated promises.

  • Use navy #0B2340 as the dominant color and lime #B8F14E for the call to action.
  • Use sans-serif typography and a left-aligned reading order.
  • Keep the wordmark plain and legible.
  • Use factual, understated copy; no unsupported claims or urgency.
  • Keep the call to action clear and secondary to the message.

02 / Review method

Make the decision reproducible.

01 — Read

Separate rules from taste

Identify mandatory requirements, examples, and exceptions before comparing assets. A pleasing image can still violate the brief.

02 — Compare

Check the same criteria

Review both options for palette, typography, hierarchy, imagery, tone, and legibility. Record observable evidence for each decision.

03 — Explain

Write a useful rationale

Name the selected option's advantage and one concrete problem in the alternative. Flag uncertainty when the brief does not resolve a case.

What if both options violate the guidelines?

Record the violations for each. Use the brief's stated priorities to choose only if a forced preference is required; otherwise flag both for revision. A preference is not the same as approval.

What if a guideline is unclear?

Identify the conflicting interpretations, include the relevant visual evidence, and request clarification. Keep the resulting decision with the guideline version so similar cases receive the same treatment.

How would I review photographic assets?

Check the specified subject, composition, crop, lighting, palette, authenticity, and any prohibited elements. Evaluate only what the image shows, and avoid inferring claims or intent that the brief does not support.
